# 部署手册

## 1. 准备

在项目根目录执行：

```bash
git lfs pull
uv sync --frozen --extra test
uv run python scripts/verify_delivery.py
```

自检结果中 `ok` 应为 `true`。

## 2. 配置

编辑 `configs/site.yaml`：

- 可见光画面使用 `power_visible`；
- 旧 CCTV 或热成像画面使用 `legacy_mixed`；
- `runtime.device` 留空时自动选择设备；
- 按现场画面修改围栏 `polygon`；
- 按现场制度修改授权人员和时段。

## 3. 启动

```bash
uv run python scripts/alarm_server.py --port 18088
TASK=all SOURCE=video.mp4 scripts/run_inspection.sh
```

运行摄像头 0：

```bash
TASK=all SOURCE=0 scripts/run_inspection.sh
```

## 4. 对外告警服务

```bash
export ALARM_TOKEN='replace-with-a-random-secret'
uv run python scripts/alarm_server.py --host 0.0.0.0 --port 18088
```

除 `/health` 外，告警写入、查询和确认接口均需要 Bearer 令牌。

## 5. 上线检查

1. 自检返回 `ok: true`；
2. 围栏坐标与现场画面一致；
3. 身份上下文能正常更新；
4. MCB 检测和 OPEN/CLOSED 状态稳定；
5. 手动模拟一次告警和恢复；
6. 检查告警服务的 `/health`。
