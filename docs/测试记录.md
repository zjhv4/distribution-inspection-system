# 测试记录

测试日期：2026-08-03 至 2026-08-12

## 1. 人员检测

可见光模型在独立测试集上的 Precision 为 0.966，Recall 为 0.907，mAP50 为 0.921。207 张配电、变电背景图中有 1 张触发人员误报。

## 2. 人员进入事件

使用 30 帧可见光视频进行全链路测试。画面中两名人员分别取得 track ID 1 和 2，并在第 3 帧进入稳定判定。测试采用待复核身份场景，两个 `PERSON_ACCESS_REVIEW` 事件均由后端确认接收。

## 3. 断路器时序事件

真实英式配电箱视频中包含10台黑色 MCB、2台 RCD 和1台总隔离开关。设备检测按实际类型分别输出，只有 MCB 进入拨杆状态和时序事件判断。箱门关闭或设备完全被遮挡时不输出设备标签。

设备检测模型在保留测试集上的 Precision 为0.980、Recall 为0.977、mAP50 为0.984、mAP50-95 为0.931。MCB 状态分类模型在保留测试集上的 Top-1 准确率为0.930。状态输出设置了置信度门槛；CLOSED 需同时经过拨杆方向和连续帧确认，否则改为 `UNKNOWN`。

使用可重复的状态输入序列验证了两类事件流程：

- 短时 OPEN 后恢复 CLOSE：生成 `MICRO_TRIP START/RECOVERED`；
- 持续 OPEN：生成 `TRIP START`，恢复后生成 `RECOVERED`。

测试覆盖短时状态偏离、持续状态偏离、恢复、检测间断、计划操作抑制和辅助信号确认。

完整视频共32414帧，时长1086.26秒。0至20秒箱门关闭时，MCB、RCD和总隔离开关的平均检测数均为0；440至460秒清晰画面平均检测为10台 MCB、2台 RCD和1台总隔离开关。全片未输出错误 `CLOSED`，手部遮挡时改为 `UNKNOWN`，设备不可见时不显示标签。
